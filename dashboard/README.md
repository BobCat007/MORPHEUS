# MORPHEUS SOC Dashboard

The MORPHEUS dashboard is a React application built with Vite. It provides a web interface for viewing and investigating honeypot telemetry and security intelligence.

## Requirements

- Node.js and npm
- The MORPHEUS repository
- The MORPHEUS API running locally on `127.0.0.1:8000`

## Install dependencies

From the repository root:

```bash
cd dashboard
npm ci
